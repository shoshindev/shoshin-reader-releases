# Shoshin Reader

Builds of Shoshin Reader, a minimal EPUB reader, for Macs with Apple Silicon.

Download the `.dmg` file from the [latest release](https://github.com/shoshindev/shoshin-reader-releases/releases/latest), open it, and drag Shoshin Reader to Applications. After that, the app looks for new versions here when it starts and offers to install them.
